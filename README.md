### 👩‍💻 Sobre mí

Apasionada por la intersección entre el **hardware**, la **robótica** y los modelos avanzados de **inteligencia artificial**. Me enfoco en desarrollar sistemas inteligentes, robótica móvil autónoma, procesamiento de visión por computador y firmware robusto para sistemas embebidos.

- 🔭 **Actualmente trabajando en:** Navegación y toma de decisiones para rovers autónomos mediante modelos de visión-lenguaje (**VLM / LLMs**) y **ROS 2**.
- 🧠 **Áreas de interés:** Robótica Móvil, Visión Artificial, Edge AI, Sistemas de Tiempo Real y Arquitectura de Sistemas Embebidos.
- 🛠️ **En mi día a día uso:** Python, C++, ROS 2, Linux y microcontroladores (STM32, Arduino).
- 💬 **Hablemos de:** Robótica, modelos multimodales, desarrollo de software o nuevos desafíos tecnológicos.
